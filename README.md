# ai-skills

Reusable Codex skills maintained by Opsolving.

## Skills

- [homearo-promotional-images](./homearo-promotional-images/SKILL.md) - Create distinct Homearo images and matching 15–20-word story captions, starting with the bare portal address and hyphen, without profile mentions, at least five real-estate hashtags after a blank line on every platform, and one-shot pasting.
- [opsolving-docs-ai-context](./opsolving-docs-ai-context/SKILL.md) - Read shared technical and business documentation and keep it aligned with project changes.
- [opsolving-local](./opsolving-local/SKILL.md) - Work safely in directly opened Git projects and multi-repository workspaces.
- [opsolving-release](./opsolving-release/SKILL.md) - Release projects through established Git tags, verify builds, and apply Argo-managed deployments.

The Airflow, Python API, Vue 3, Bitnami-style Helm and Terraform implementation skills are maintained in the MCP Skills service at `https://mcp.psem.io/mcp/skills`. Use `list_skills`, `get_skill` and `get_skill_file` to read their complete packages.
