# ai-skills

Reusable Codex skills maintained by Opsolving.

## Skills

- [homearo-promotional-images](./homearo-promotional-images/SKILL.md) - Design distinct Homearo images and single-sentence captions starting with the portal address, mandatory parenthesized @ text pasted with the complete caption in one action, and at least five real-estate hashtags on a separate line below the description.
- [opsolving-airflow-dags](./opsolving-airflow-dags/SKILL.md) - Build layered Airflow DAG repositories with explicit instances, processes, and reusable libraries.
- [opsolving-app-python-api](./opsolving-app-python-api/SKILL.md) - Build layered FastAPI applications with SQLAlchemy ORM models, request-scoped sessions, repositories, and Alembic migrations.
- [opsolving-app-vue3](./opsolving-app-vue3/SKILL.md) - Build structured Vue 3 applications with router-driven views, typed components, explicit state, and lifecycle boundaries.
- [opsolving-bitnami-chart](./opsolving-bitnami-chart/SKILL.md) - Build Bitnami-style Helm charts with the Opsolving common library.
- [opsolving-docs-ai-context](./opsolving-docs-ai-context/SKILL.md) - Read shared technical and business documentation and keep it aligned with project changes.
- [opsolving-local](./opsolving-local/SKILL.md) - Work safely in directly opened Git projects and multi-repository workspaces.
- [opsolving-release](./opsolving-release/SKILL.md) - Release projects through established Git tags, verify builds, and apply Argo-managed deployments.
- [opsolving-terraform-module](./opsolving-terraform-module/SKILL.md) - Build complete Terraform modules with stable resource identities and full provider-resource coverage.
